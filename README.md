## 🚀 项目简介

**HolliCube OS** 是和利时卡优倍公司开源的一款轻量、高效、可扩展的工业数字操作系统。旨在为工业领域的开发者和系统集成商，提供数据采集、设备管理、实时监控与数据可视化的基础框架。通过开源，我们希望能够与社区共同推动工业互联网技术的创新与普及，构建一个开放、协作的工业软件生态。

**商业版与开源版**: 此开源版本是和利时卡优倍工业物联网平台的重要组成部分。我们同时提供功能更完善、包含企业级技术支持与服务的商业版本。如需了解商业版本详情，请扫码添加微信。

## ✨ 核心特性

1. **自主可控**：基于信创生态适配，支持国产化环境部署；平台架构全栈自研，自带高性能工业时序数据库，支持高并发写入与查询；开放式微服务架构，支持用户自主配置、自主部署、自主服务；通过等保三级认证。
2. **异构数据连接**：支持100+主流工业协议和通信标准，快速对接PLC、SCADA、DCS、MES、ERP等设备与系统。
3. **边缘实时计算**：边缘节点支持每秒10万+时序数据写入，50ms级控制响应；具备现场自治计算与脱网运行能力。
4. **工业信息建模**：支持面向五要素（属性、方案、时间、报警、逻辑）的统一工业建模框架，构建从设备 → 产线 → 车间 → 工厂的层级模型体系。
5. **工业智能**：构建语义化建模+AI大/小模型融合架构，支持知识推理、预测优化、实时识别等业务智能；具备模型复用、调优、自学习能力。
6. **协同控制**：实现从人、机、系统、流程的闭环协同控制，涵盖排产调度、设备执行、状态反馈、事件联动等全过程；支持边缘联动控制、业务规则驱动、工艺流程编排，真正让“平台指挥 → 现场响应”成为现实。
7. **数据资产与治理**：提供系统化数据资产管理体系，包括数据目录、标签体系、指标模型、权限管理、质量校验与生命周期控制，实现数据从“可读”到“可用”、从“数据”到“资产”的跨越。
8. **低代码开发**：提供可视化开发平台，内置MOM（制造运营管理）典型应用模板库，支持拖拽式页面搭建、逻辑编排、数据调用；企业可快速生成车间看板、任务工单、质检报表等业务应用，提升开发效率与响应速度。
9. **云边协同**：提供可视化开发平台，内置MOM（制造运营管理）典型应用模板库，支持拖拽式页面搭建、逻辑编排、数据调用；企业可快速生成车间看板、任务工单、质检报表等业务应用，提升开发效率与响应速度。
